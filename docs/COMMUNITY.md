# Loculary — Community

Community is a later phase and must not turn Loculary into a social network.

Authenticated users may eventually propose tools, rate tools, comment, report content, create public collections and receive contributor credit. Ratings and comments require accounts; a user has one active rating per tool and can change it.

Comments need anti-spam, reporting, moderation status/history and appropriate controls. Proposal flow: proposal → automatic validation → review → moderation/human validation → publication. Proposals may be rejected, merged, transformed or paused.

Contributor roles: original author, contributor, translator, improver, maintainer. Attribution remains discreet during tool use. Moderation automation may classify safe/suspicious/blocked, but human review remains available.
