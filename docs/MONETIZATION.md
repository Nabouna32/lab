# Loculary — Monetization

Loculary is intended to remain free, with advertising as a possible primary revenue source.

Ads must never interrupt the primary tool action. Desktop side placements are preferred where space allows; smaller layouts may use non-intrusive placements. Never place an ad between an input and its result.

Use an AdSlot/provider abstraction so the advertising vendor can change or be disabled without changing individual tools. Infrastructure spending should remain proportional to demonstrated usage and revenue.
