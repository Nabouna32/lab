# Loculary — Accessibility

WCAG 2.2 AA is the target and accessibility belongs in the tool quality gate.

Core requirements: keyboard operation, logical focus, semantic structure, accessible names, sufficient contrast, understandable errors, meaningful status announcements, non-color-only information, touch-friendly interaction and responsive mobile behavior.

Animation preference can be off, reduced, normal or playful. The system prefers-reduced-motion setting takes precedence over playful motion.

Mobile, tablet, desktop and large screens are first-class contexts. A future child mode would require separate safety, privacy, legal and advertising design.
