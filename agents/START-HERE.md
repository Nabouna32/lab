# Loculary — Work Entry Point

Use this guide to find the right instructions when starting or resuming work. The root `AGENTS.md` remains the repository's primary agent entry point and contains repository-specific rules. The common contract below defines shared collaboration and delivery principles; task guides add only domain-specific requirements.

## Start or resume work

1. Read the current `AGENTS.md`, this guide, `agents/AGENT-CONTRACT.md` and `agents/PRODUCT-ISSUE-CONTRACT.md` through the available repository tools. Do not assume remote files were already loaded.
2. Read the complete active mission Issue and relevant comments; reconcile its checkpoint with current branches, PRs, checks and repository state.
3. Read the canonical product/UX/architecture/privacy documents and decisions relevant to the task.
4. Read the applicable specialist guide:
   - Product and documentation: `agents/product/PRODUCT-WORKFLOW.md`
   - Features: `agents/features/FEATURE-WORKFLOW.md`
   - Tools: `agents/tools/TOOL-WORKFLOW.md`
5. If a required source cannot be read, state the exact limitation and do not present dependent conclusions as verified. Resolve conflicts between active instructions explicitly.

## Where rules live

- `AGENTS.md`: repository entry point, technical constraints, project-specific conventions and validation/deployment rules.
- `agents/AGENT-CONTRACT.md`: shared collaboration, decision-making, evidence, continuity and delivery principles.
- `agents/PRODUCT-ISSUE-CONTRACT.md`: how to use Issues as durable plans and checkpoints for resumable work.
- Specialist workflow guides: only the additional requirements specific to their task domain.

Keep these files complementary. Prefer a clear reference to the canonical rule over copying the same rule into multiple guides.
