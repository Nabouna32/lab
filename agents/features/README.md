# Feature implementation workflow

Use FEATURE-FACTORY-CONTRACT.md as the canonical procedure for implementing a validated Loculary feature. FEATURE-WORKFLOW.md is a short launch checklist for the same assistant, not a separate role or delegated worker.

Before implementation, inspect the active mission Issue, current main, relevant code, canonical documents, branches and PRs. Challenge the requested approach, identify optimizations and alternatives, validate consequential decisions, then implement one approved scope at a time.

Complete relevant code, UX, accessibility, responsive behavior, i18n, tests and documentation. Inspect the diff and run applicable checks. Deliver through the repository's Git/PR/CI workflow and update the mission Issue at meaningful milestones.
